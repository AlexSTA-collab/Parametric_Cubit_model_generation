┌─────────────────────────────────────────────────────────────────────────┐
│                    DETAILED WORKFLOW (Per Family/Angle)                 │
└─────────────────────────────────────────────────────────────────────────┘


For EACH family (soft, stiff, initial) × angle (0, 10):


    START: {family}/angle_{X}/
           ↓
    ┌──────────────────────────────────────────────────────────────┐
    │  PHASE 1: INTERFACE MODELS                                   │
    │                                                               │
    │  For h in [0.01, 0.02, 0.04, 0.06, 0.08, 0.1]:              │
    │                                                               │
    │    mesh_generation/Interface_models/                         │
    │         Template_angle_{X}_h_{h}.inp                         │
    │              ↓                                                │
    │    Generate Job File                                         │
    │         + Substitute E_M, E_I, E_0 (family params)          │
    │         + Update paths to mesh_generation/angle_{X}/height_* │
    │              ↓                                                │
    │    {family}/angle_{X}/Interface_models/                      │
    │         *_h_{h}_job.inp                                      │
    │              ↓                                                │
    │    Run Solver (edelweissfe)                                  │
    │              ↓                                                │
    │    Output: 3 × .case files                                   │
    │         Cohesive_zone_model_bottom_{h}.case                  │
    │         Cohesive_zone_model_interface_{h}.case               │
    │         Cohesive_zone_model_top_{h}.case                     │
    │              ↓                                                │
    │    Run Postprocessing (pvpython)                             │
    │         + Extract traction jumps                             │
    │         + Extract displacement jumps                         │
    │              ↓                                                │
    │    Output: cases/Interface_h_{h}_angle_{X}.pkl               │
    │                                                               │
    └──────────────────────────────────────────────────────────────┘
           ↓
    ┌──────────────────────────────────────────────────────────────┐
    │  PHASE 2: FULL LAYER MODEL (Reference)                       │
    │                                                               │
    │  For h = 0.01 ONLY:                                          │
    │                                                               │
    │    mesh_generation/Full_layer_models/                        │
    │         Template_angle_{X}_h_0.01.inp                        │
    │              ↓                                                │
    │    Generate Job File                                         │
    │         + Substitute E_M, E_I (full layer params)           │
    │         + Update paths to mesh_generation/angle_{X}/height_* │
    │              ↓                                                │
    │    {family}/angle_{X}/Full_layer_models/                     │
    │         *_h_0.01_job.inp                                     │
    │              ↓                                                │
    │    Run Solver (edelweissfe)                                  │
    │              ↓                                                │
    │    Output: 3 × .case files                                   │
    │         Cauchy_Full_model_bottom_0.01.case                   │
    │         Cauchy_Full_model_middle_0.01.case                   │
    │         Cauchy_Full_model_top_0.01.case                      │
    │              ↓                                                │
    │    Run Postprocessing (pvpython)                             │
    │         + Extract reference traction jumps                   │
    │         + Extract reference displacement jumps               │
    │              ↓                                                │
    │    Output: cases/Full_h_0.01_angle_{X}.pkl                   │
    │                                                               │
    └──────────────────────────────────────────────────────────────┘
           ↓
    ┌──────────────────────────────────────────────────────────────┐
    │  PHASE 3: CONVERGENCE ANALYSIS                               │
    │                                                               │
    │    Input:                                                     │
    │      - Interface_models/cases/*.pkl (6 heights)              │
    │      - Full_layer_models/cases/*.pkl (reference)             │
    │              ↓                                                │
    │    Run convergence_analysis.py                               │
    │         + Compare Interface vs Full for each height          │
    │         + Compute L1 errors                                  │
    │         + Generate convergence plots                         │
    │              ↓                                                │
    │    Output: comparison_results/                               │
    │      - Interface_vs_Full_convergence_L1_error_angle_{X}.pkl  │
    │      - Convergence plots (*.png)                             │
    │                                                               │
    └──────────────────────────────────────────────────────────────┘
           ↓
    END: Family {family}, Angle {X} Complete
