# Force-Displacement Evaluation Scripts

This directory contains scripts for extracting and analyzing force-displacement curves from ParaView output files generated by the viscoelastic interface analyses.

## Contents

### Main Scripts

1. **`Paraview_plot_Extraction_script.py`**
   - Extracts displacement, reaction force, interface force, and surface stress data from ParaView `.case` files
   - Computes derived viscoelastic parameters
   - Generates plots for reaction-displacement and force-stress curves
   - Saves data as pickled dictionary for further analysis

2. **`run_paraview_extraction.sh`**
   - Wrapper script to run ParaView extraction with proper parameters
   - Automatically called by the master workflow after each analysis completes

### Jupyter Notebooks

The following notebooks analyze the extracted force-displacement data for different E₀ values:

- `Creep_Tests_Results.ipynb` - General creep test analysis
- `Creep_Tests_Results_E0_e-8.ipynb` - Analysis for E₀ = 10⁻⁸
- `Creep_Tests_Results_E0_e-4.ipynb` - Analysis for E₀ = 10⁻⁴  
- `Creep_Tests_Results_E0_e4.ipynb` - Analysis for E₀ = 10⁴
- `Creep_Tests_Results_E0_e8.ipynb` - Analysis for E₀ = 10⁸

## Usage

### Automatic Extraction (Recommended)

The ParaView extraction is automatically run by the master workflow:

```bash
# Run complete viscoelastic study (includes automatic extraction)
./run_viscoelastic_study.sh [family] [angle] [m_value] [n_value]
```

### Manual Extraction

If you need to run extraction manually for specific results:

```bash
cd evaluate_force_displacement_scripts
./run_paraview_extraction.sh \
    <work_dir> \
    <out_dir> \
    <E_M> <E_I> <E_0> \
    <h> <m> <n> \
    <family> <angle>
```

**Example:**
```bash
./run_paraview_extraction.sh \
    ../stiff/angle_0/m_elastic_limit_n_4e7/Interface_models \
    ../stiff/angle_0/m_elastic_limit_n_4e7/Interface_models/force_displacement_results \
    2e5 4e3 4e7 \
    0.01 1e8 4e7 \
    stiff 0
```

### Analyzing Results with Jupyter Notebooks

1. Start Jupyter:
   ```bash
   jupyter notebook
   ```

2. Open the appropriate notebook for your E₀ value

3. Update the path to the pickled data file in the notebook:
   ```python
   with open("../family/angle_X/m_Y_n_Z/Interface_models/force_displacement_results/parametric_curves_creep.pkl", "rb") as f:
       parametric_curves_creep = pickle.load(f)
   ```

4. Run all cells to generate analysis plots

## Extracted Data

The `parametric_curves_creep.pkl` file contains dictionaries with:

- **Keys**: Derived parameter identifiers (combinations of h, E_eff, m, n)
- **Values**: Lists containing:
  - `[0]`: displacement_top_magnitude (numpy array)
  - `[1]`: force_interface_magnitude (numpy array)  
  - `[2]`: surface_stress_interface_magnitude (numpy array)

## Parameters

### Material Parameters
- `E_M`: Matrix Young's modulus [MPa]
- `E_I`: Inclusion stiffness [MPa/mm]
- `E_0`: Interface stiffness [MPa/mm]
- `h`: Layer height [m]

### Viscoelastic Parameters
- `m`: Elastic stiffness parameter
  - `1e8`: Elastic limit (nearly elastic)
  - `1e0`: Viscoelastic (intermediate)
  - `1e-8`: Viscous limit (nearly viscous)
- `n`: Viscous stiffness parameter
  - Values: `4e7`, `4e3`, `4e-5`

### Derived Parameters
- `m_Ju`, `n_Ju`: Jump-based material parameters
- `m_Js`, `n_Js`: Stress-based material parameters
- `E_u_eff`: Effective displacement-based stiffness
- `E_s_eff`: Effective stress-based stiffness

## Requirements

- ParaView with pvpython
- Python packages: numpy, matplotlib, pickle
- Mamba environment: `alexandros_Plot`

## Integration with Workflow

This directory is integrated into the main parametric study workflow:

1. **Mesh Generation**: Creates template files with viscoelastic parameters
2. **Analysis Execution**: Runs FE solver with parameter substitution
3. **Standard Postprocessing**: Computes traction/displacement jumps
4. **Force-Displacement Extraction**: ← **This step** extracts curves from ParaView
5. **Jupyter Analysis**: Analyzes extracted data with notebooks

## Troubleshooting

### ParaView Extraction Fails

Check the log file:
```bash
cat family/angle_X/m_Y_n_Z/Interface_models/paraview_h_H_m_M_n_N.log
```

Common issues:
- Missing `.case` files → Check solver completed successfully
- Wrong column names → Update `pick_col()` calls in extraction script
- pvpython not found → Activate correct conda environment

### Missing Data in Notebooks

- Verify pickle file exists and is not empty
- Check that extraction completed without errors
- Ensure correct file path in notebook

## Notes

- ParaView extraction is non-critical - workflow continues if it fails
- Standard traction/displacement postprocessing runs independently
- Each (m,n) combination generates separate result directories
- Pickle files are updated/created if they exist/don't exist
